# 공부일지 — 배포 가이드

공부 계획·타이머·포인트 앱이에요. **전부 무료**로 운영할 수 있고, 휴대폰 홈 화면에 설치하면 아이콘을 눌러 앱처럼 바로 열려요.
- **로그인 없이** 바로 쓸 수 있어요. 기록은 그 기기에 저장돼요.
- **앱 전용 아이디·비밀번호**로 로그인하면 기록이 서버에 저장돼서 다른 기기에서도 이어서 쓸 수 있어요. 이메일·전화번호·구글 계정은 안 써요.
- 로그인하고 **반 코드**로 반에 들어가면 총 포인트·총 공부 시간 랭킹, 지금 공부 중인 친구, 반 시험·수행평가 일정을 같이 볼 수 있어요.

## 비용: 0원

| 쓰는 것 | 요금 |
|---|---|
| GitHub Pages (앱 주소) | 무료 |
| Firebase Spark 요금제 (로그인·데이터베이스) | 무료, 카드 등록 없음. 한도를 넘으면 돈이 나가는 대신 그날만 멈춰요 |
| 홈 화면 설치 (웹앱) | 무료. 앱스토어 등록 필요 없음 |

> 참고로 플레이스토어에 올리려면 개발자 등록비 25달러(1회), 앱스토어는 연 99달러가 들어요. 이 앱은 홈 화면 설치 방식이라 필요 없어요.
> Firebase에서 **Blaze(종량제)로 업그레이드하라는 안내가 나와도 누르지 마세요.** 이 앱은 Spark로 충분해요.

## 파일

| 파일 | 하는 일 |
|---|---|
| `index.html` | 앱 화면 전체 |
| `manifest.json` | 앱 이름·아이콘 정보 (홈 화면 설치용) |
| `sw.js` | 아이콘 눌러 빠르게 열리고, 인터넷 없이도 열리게 함 |
| `icon-192.png`, `icon-512.png`, `icon-maskable-512.png`, `apple-touch-icon.png`, `favicon-32.png` | 앱 아이콘 |
| `og-image.png` | 카카오톡에 링크 보낼 때 뜨는 미리보기 그림 |
| `firestore.rules` | 서버 보안 규칙 (GitHub에는 안 올려도 돼요. Firebase 콘솔에 붙여 넣기) |

`index.html`의 `const FIREBASE_CONFIG = null;`이 그대로면 **체험 모드**로 열려요. 체험 모드에서는 계정이 그 기기에만 저장되고, 반 친구와 반 일정은 예시예요. 아래 순서대로 하면 진짜 서버가 연결돼요.

---

## 1. Firebase 프로젝트 만들기 (무료)

1. https://console.firebase.google.com 에 구글 계정으로 들어가요. (서버 관리자인 나만 구글 계정을 써요. 학생들은 안 써요.)
2. **프로젝트 추가** → 이름(예: `gongbu-ilji`) → Google 애널리틱스는 꺼도 돼요 → 만들기.
3. 프로젝트 첫 화면에서 **웹 아이콘 `</>`** 을 눌러 웹 앱을 추가해요. 앱 이름은 아무거나 써도 되고, Firebase 호스팅 체크는 안 해도 돼요.
4. 화면에 나오는 `const firebaseConfig = { ... };` 부분을 복사해요.

## 2. 설정 붙여 넣기

`index.html`을 메모장이나 VS Code로 열고 아래 줄을 찾아요. (맨 위의 `---` 두 줄은 지우지 마세요. 카톡 미리보기에 필요해요.)

```js
const FIREBASE_CONFIG = null;
```

`null` 자리에 복사한 `{ ... }`를 넣어요.

```js
const FIREBASE_CONFIG = {
  apiKey: "AIza....",
  authDomain: "gongbu-ilji.firebaseapp.com",
  projectId: "gongbu-ilji",
  storageBucket: "gongbu-ilji.appspot.com",
  messagingSenderId: "1234567890",
  appId: "1:1234567890:web:abcd1234"
};
```

> `apiKey`가 코드에 보여도 괜찮아요. Firebase 웹 앱은 원래 이렇게 써요. 데이터는 3단계의 보안 규칙이 지켜요.

## 3. 로그인과 데이터베이스 켜기

**아이디 로그인 켜기**
1. 왼쪽 메뉴 **빌드 → Authentication** → 시작하기.
2. **로그인 방법** 탭 → **이메일/비밀번호** → 사용 설정 → 저장. (아래의 "이메일 링크"는 켜지 않아요.)

앱은 학생이 만든 아이디를 서버 안에서만 `아이디@users.gongbu-ilji.app` 같은 가짜 주소로 바꿔 저장해요. 그래서 Firebase가 이 방식을 쓰지만, 학생에게 이메일을 묻거나 메일을 보내는 일은 없어요. 비밀번호는 4자 이상이면 돼요.

**Firestore 데이터베이스**
1. 왼쪽 메뉴 **빌드 → Firestore Database** → 데이터베이스 만들기.
2. 위치는 **asia-northeast3 (서울)** 을 고르고, **프로덕션 모드**로 시작해요.
3. **규칙** 탭을 열고, 원래 있던 내용을 지운 뒤 `firestore.rules` 내용을 전부 붙여 넣고 **게시**를 눌러요.

> 예전 버전 규칙을 이미 게시했다면 새 `firestore.rules`로 다시 붙여 넣고 게시해 주세요.

## 4. GitHub Pages로 배포 (무료 링크 만들기)

1. https://github.com 에서 **New repository** → 이름(예: `gongbu-ilji`) → **Public** → 만들기.
2. **Add file → Upload files**로 압축을 푼 파일을 **전부** 끌어다 놓고 **Commit changes**를 눌러요. (`index.html`, `manifest.json`, `sw.js`, `og-image.png`, 아이콘 PNG 5개)
3. 저장소의 **Settings → Pages**로 가요. Source는 **Deploy from a branch**, Branch는 **main / (root)** 로 고르고 저장해요.
4. 1~2분 뒤 `https://내아이디.github.io/gongbu-ilji/` 주소가 생겨요.

수정할 때는 바뀐 파일만 다시 업로드하면 1~2분 뒤 반영돼요. 이미 설치한 친구들도 다음에 열 때 자동으로 새 버전을 받아요.

## 5. 테스트

1. 휴대폰과 컴퓨터(또는 크롬 일반 창과 시크릿 창)에서 주소를 열어요.
2. 한쪽에서 **설정 → 가입하기**로 아이디를 만들고, **반 → 새 반 만들기**를 누르면 6자리 코드가 나와요.
3. 다른 쪽에서 다른 아이디로 가입하고 **반 참가**에 그 코드를 넣어요.
4. 한쪽에서 타이머를 켜면, 다른 쪽 "지금 공부 중"에 바로 떠야 해요.
5. 한쪽에서 **일정 → 우리 반에 공유**로 시험 일정을 넣으면, 다른 쪽 일정에도 떠야 해요.
6. 같은 아이디로 다른 기기에서 로그인하면 계획·기록이 그대로 나와야 해요.

## 6. 앱처럼 설치하기 (홈 화면 아이콘)

배포한 주소를 휴대폰에서 열면 오늘 화면 맨 위에 **"공부일지를 앱으로 설치"** 안내가 떠요. 설정 화면에도 있어요.

| 휴대폰 | 설치 방법 |
|---|---|
| 안드로이드 (크롬, 삼성 인터넷) | 안내 카드의 **앱 설치** 버튼 → 설치 |
| 아이폰 (사파리) | 아래쪽 **공유 버튼** → **홈 화면에 추가** |
| 카카오톡 안에서 열었을 때 | 자동으로 크롬·사파리로 넘어가요. 안 넘어가면 **다른 브라우저로 열기** 버튼 |
| 컴퓨터 (크롬, 엣지) | 주소창 오른쪽 설치 아이콘 또는 안내 카드의 **앱 설치** |

설치하면 주소창 없이 전체 화면으로 열리고, 인터넷이 없어도 열려요. 계획·타이머·기록은 인터넷 없이도 되고, 반 랭킹과 계정 저장은 인터넷이 다시 연결되면 돼요.

## 7. 반에 공유

반 화면의 **초대 링크 복사**를 눌러 단톡방에 붙여 넣으면 돼요. 링크를 열면 반 코드가 자동으로 채워져요.

카톡에 링크를 보내면 **"공부일지 · 우리 반 공부 앱"** 제목과 그림이 있는 미리보기 카드가 자동으로 떠요. 따로 할 일은 없어요. (GitHub Pages가 `index.html` 안의 `{{ site.github.url }}`을 내 주소로 바꿔 줘요.)
- 미리보기가 예전 모습으로 뜨면 카카오 **공유 디버거**(https://developers.kakao.com/tool/debugger/sharing)에 내 주소를 넣고 **캐시 초기화**를 누르세요.
- `index.html`을 고칠 때 `{{` 나 `{%` 같은 글자를 새로 넣으면 GitHub Pages가 오류를 낼 수 있어요.

친구들에게는 이렇게 안내해 주세요.
- 링크를 열고 **설정 → 가입하기**로 아이디·비밀번호를 만들면 돼요. 이메일은 필요 없어요.
- **비밀번호를 잊으면 찾을 수 없어요.** 로그인한 상태에서는 설정에서 비밀번호를 바꿀 수 있어요.
- 링크를 열면 나오는 안내대로 **앱 설치**(아이폰은 공유 → 홈 화면에 추가)를 하면 아이콘을 눌러 바로 열려요.

## 알아 둘 것

- **반에 보이는 정보:** 아이디, 총 포인트, 총 공부 시간, 지금 공부 중인 과목, 반에 공유한 일정. 계획 내용과 공부 기록은 본인만 볼 수 있어요.
- **알림:** 시험·수행평가는 하루 전과 당일에 일정 탭에 빨간 점이 뜨고, 오늘 화면 맨 위에 나와요. 앱을 닫아도 휴대폰 알림이 오게 하려면 Firebase 유료 요금제(Blaze)와 서버 함수가 필요해서 지금은 안 넣었어요.
- **무료 사용량:** Firebase 무료 요금제(Spark)는 하루 읽기 5만 번, 쓰기 2만 번까지예요. 앱은 바뀐 게 있을 때만 서버에 올려서 한 반(30명 안팎)이 쓰기에는 충분해요.
- **점수는 각자 기기에서 계산해요.** 보안 규칙이 말도 안 되는 값은 막지만, 마음먹고 조작하는 것까지는 막지 못해요. 반 친구끼리 쓰는 용도로 생각하고 만들었어요.
- **기록 저장 한도:** 한 사람의 기록은 서버에 최대 약 1MB까지 저장돼요. 하루 몇 번씩 써도 몇 년은 충분해요.
- **비밀번호를 잊은 학생:** 관리자도 비밀번호를 알 수 없어요. Firebase 콘솔 **Authentication → 사용자**에서 그 아이디를 삭제하면 같은 아이디로 다시 가입할 수 있어요. 다만 그 계정의 서버 기록은 새 계정과 연결되지 않아요.

## 안 될 때

| 증상 | 확인할 것 |
|---|---|
| "서버에 연결하지 못했어요" | `FIREBASE_CONFIG`를 쉼표·괄호까지 정확히 붙여 넣었는지 |
| "서버에서 아이디 로그인이 아직 꺼져 있어요" | Authentication에서 **이메일/비밀번호**를 켰는지 |
| 반 만들기·일정 공유에서 "실패했어요" | Firestore를 만들었는지, **새** 규칙을 **게시**했는지 |
| "없는 반 코드예요" | 코드 6자리를 정확히 넣었는지 (0과 O, 1과 I는 코드에 쓰지 않아요) |
| 그래도 모르겠으면 | 브라우저 개발자 도구(F12) → Console의 빨간 오류 메시지를 확인 |
